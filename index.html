Local AI Lab: Beyond ChatGPT

A cozy, interactive look at building a 100% local Python coding assistant on an older i7 ThinkPad with 12 GB RAM using Ollama and Qwen3 1.7B.

Checking localhost:11434... Simulation fallback ready for web visitors
Project Goal: Run a local AI on a ThinkPad that analyzes Python code, finds and explains bugs, suggests improvements, communicates via Python, and integrates into VS Code—without subscriptions or cloud APIs.
Phase 1

Preparing the Local Model

Because the ThinkPad has 12 GB RAM and an older i7 processor, we chose qwen3:1.7b over the larger 4B model so live demos stay responsive.

ollama run qwen3:1.7b
# Test prompt: Explain the difference between a Python list and a tuple.
# Exit with /bye and verify installed models:
ollama list
Phase 2

Connecting Ollama with Python

We isolated the project in a virtual environment and installed the Ollama Python library so our script can talk to the local service on port 11434.

mkdir ~/local-ai-coding-assistant
cd ~/local-ai-coding-assistant
python3 -m venv .venv
source .venv/bin/activate
pip install ollama
Phase 3

VS Code Integration

To move beyond the terminal, we installed the official Ollama extension in VS Code (v1.127+), which connects directly to 127.0.0.1:11434 for inline chat.

Phase 4

Git & GitKraken Workflow

Every stage—from assistant.py and buggy.py to this interactive website—was staged, committed, and pushed to GitHub using GitKraken.
